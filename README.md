# RDX MARKET - Digital Accounts & Assets Store

A high-performance, dark-themed digital goods marketplace built for instant delivery, automated escrow guarantees, and seamless checkout with UPI and USDT.

## 🚀 Features

- **⚡ Instant 1-Second Auto-Delivery**: Automated credentials delivery with login, password, 2FA backup codes, cookies, session files, and setup instructions.
- **🛡️ Escrow & Replacement Guarantee**: 24h to 48h protection on every account with one-click dispute resolution.
- **💳 Multi-Currency Checkout**: Full support for Indian UPI (PhonePe, GPay, Paytm, QR) and Crypto USDT (TRC20 / BEP20 / Polygon) with real-time conversion.
- **📦 Preloaded Stock**: Comprehensive catalog of Telegram sessions (+62, +92, +234, +1, +44), Steam (GTA V, CS2, Rust), Instagram aged accounts, YouTube channels, Discord aged tokens, TikTok creator rewards, and more.
- **👑 Admin Panel**: Manage profit margins, add custom accounts, review orders, and sync wholesale stocks.
- **📱 Fully Responsive**: Optimized for mobile, tablet, and desktop with zero-lag modern UI.

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS with custom gaming theme
- **Icons**: Lucide React
- **Storage**: LocalStorage state persistence with cloud ready structure

## 📦 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone <your-repo-url>
   cd rdx-market
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel / Cloudflare Pages / Netlify

1. Push this code to your GitHub account repository.
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Select your GitHub repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**.
6. Connect your custom domain `rdxmarket.com` under **Project Settings > Domains**.
